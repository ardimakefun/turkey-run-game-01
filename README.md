Turkey Run — a zero-dependency, offline-first HTML5 Canvas arcade escape game. Bust off the Thanksgiving cloche, outrun Farmer Barnaby through the farmhouse kitchen, the barn yard and the autumn woods, parry carving knives back at him with Dash Parry and Gobble Wave, ride the Fever, and reach the Turkey Sanctuary 1,000m away. Four turkey skins, seven achievements, three zones plus Endless Panic.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Or open `game/index.html` directly — the game runs from `file://` with zero network requests.

Controls: Space / W / ↑ / left-click to jump, flap and glide; S / ↓ / right-click to slide; Shift / E / D / middle-click to Dash Parry; F / G to fire the Gobble Wave; P to pause; M to mute; R to restart.
